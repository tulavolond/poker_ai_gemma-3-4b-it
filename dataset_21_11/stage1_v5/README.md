Дальше — ступень 2, ровно на этой архитектуре: движок считает ауты и эквити, модель применяет правило «эквити против пот-оддсов» и выдаёт <action>. Это уже прямая дорога к твоей исходной цели — решениям по ставкам. Но сначала закроем иерархию: пришли оба замера.

# Правило, которое учит модель
Эквити ≥ пот-оддсы  →  Колл
Эквити <  пот-оддсы  →  Фолд
При точном равенстве →  Колл
Имплайд-оддсы не учитываем (бонус 0).
